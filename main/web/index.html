Ping monitor

Round-trip times to the gateway, the Deco node this device is on, and up to 7 devices (the last 12 hours; Home Assistant keeps the long-term history).
The name is what Home Assistant keeps the history under: change a device's address and the same sensor carries on; rename it and you get a new sensor (the old one is removed). Give every device a different name. Each round sends 5 pings to every address. The scans have priority: a round is skipped if a scan is running or about to start. The device you ping is reached through this device's own Wi-Fi link, so the gateway line shows how much of any delay is this device's own link.

Security and device

Secrets are stored encrypted on the device and are never shown here; leave a password field empty to keep the current one. This page uses plain HTTP, so use it on your home network only.

Erase all settings

This cannot be undone. It permanently deletes everything stored on this device: the Wi-Fi details, the TP-Link account login, the MQTT login, the pinned Deco host key, the schedule, the admin password and the run history.

The device then restarts into setup mode and does nothing useful until you run setup again from a phone and re-enter every setting. While it is unconfigured the Home Assistant entities show as unavailable, and this page is unreachable until setup is done.

The hardware encryption key burned into the chip is not affected; it is not needed to be restored.
